# 迁移到 JSONSafeLoader（YAML 1.2 JSON Schema）

`JSONSafeLoader` 只改**无 tag 纯量（plain scalar）的隐式类型解析**：从 PyYAML
传统的 YAML 1.1 规则切换到 YAML 1.2 的 JSON schema。构造阶段不变，仍是
`SafeConstructor`——显式 tag 照旧走安全构造器，`!!python/*` 一律拒绝，不会
启用任何 Python 对象标签。

迁移时只需要关心下面两件事。

## 1. 哪些旧配置的类型会变

下面这些值在 `SafeLoader` 下会被转成非字符串类型，在 `JSONSafeLoader` 下
**变成字符串 `str`**（映射的键和值规则完全相同）：

| 写法示例 | SafeLoader（旧，YAML 1.1） | JSONSafeLoader（新，1.2） |
| --- | --- | --- |
| `on` `off` `yes` `no`（含大小写变体） | `bool` | `str` |
| `~` | `None` | `str` |
| `2026-11-10`、`2026-11-10T12:30:00Z` | `date` / `datetime` | `str` |
| `017`、`0755`（前导零，旧八进制） | `int`（按八进制，如 `017`→`15`） | `str`（保留原文） |
| `0o17` | `str`（PyYAML 本就不识别） | `str` |
| `0x1f`（十六进制）、`0b101`（二进制） | `int` | `str` |
| `12:30:00`、`1:30`（六十进制） | `int` | `str` |
| `.inf` `-.inf` `.nan`（含大小写变体） | `float`（`inf`/`nan`） | `str` |
| `.5`（点开头的小数） | `float` | `str`（JSON 数字要求整数位） |
| `1_000`、`1_000.5`（下划线分位） | `int` / `float` | `str` |

另有一个方向相反的变化需要注意：

| 写法示例 | SafeLoader（旧） | JSONSafeLoader（新） |
| --- | --- | --- |
| `1e3`、`2.5E-2`（科学计数法） | `str`（旧解析器不识别指数） | `float` |

保持不变的：`true`/`false`（仍是布尔）、`null`/空值（仍是 `None`）、无前导零的
十进制整数（`0`、`42`、`-7`）、常规小数（`1.5`、`5.`、`0.0`）。

## 2. 哪些值要加引号才能继续作为字符串

只有“恰好是 JSON 合法词法、但你希望保留为字符串”的值才需要加引号（单双引号
均可）。未被 JSON schema 识别的写法（上表第一组）现在默认就是字符串，**不用
加引号**；需要保留数字/布尔语义时再用显式 tag。

需要加引号的情况：

- JSON 布尔：`true`、`false`（含 `True`/`FALSE` 等大小写变体）想要字符串时写
  `"true"`、`'false'`。
- 空值与 `null`：想保留字符串 `"null"` 时写引号；想要空值保持不写或写 `null`
  即可（仍是 `None`）。
- 普通十进制整数：`0`、`42`、`-7` 想要字符串时写 `"42"`。
- JSON 浮点：`1.5`、`5.`、`1e3`、`2.5e-2` 想要字符串时写 `"1.5"`、`'1e3'`。

不需要加引号（默认即字符串）：`on`/`off`/`yes`/`no`、`~`、日期时间、
`017`/`0755`、`0o17`、`0x1f`、`0b101`、六十进制、`.inf`/`.nan`、`.5`、带下划线
的数字。

如果反过来，想让这些默认字符串继续保持原来的数值/日期语义，请使用显式 tag：
`!!int "017"`（得到 `15`）、`!!float ".5"`、`!!timestamp 2026-11-10`、
`!!bool "true"`。显式 tag 始终由安全构造器处理。
